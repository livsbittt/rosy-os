# assets

## Purpose

Non-executable images used by repository documentation. Requirements, runbooks,
and architecture decisions belong in the appropriate `docs/` subdirectory.

## Key Files

| File | Description |
|------|-------------|
| `architecture.png` | High-level Rosy OS architecture diagram |
| `rosy_pro_image.png` | Pinky Pro product image |

## For AI Agents

- Do not put Markdown requirements or deployment instructions in this folder.
- Do not regenerate or replace an image unless the documented architecture or
  product representation actually changed.
- Link to these files from Markdown with the `docs/assets/` path.

## Testing Requirements

None.
